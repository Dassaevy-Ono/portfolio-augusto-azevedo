# Portfólio — Vereador Augusto Azevedo

Cartão digital responsivo desenvolvido para apresentar a biografia e os canais oficiais do vereador Augusto Azevedo, de Boa Vista do Ramos/AM.

## Funcionalidades

- foto oficial e apresentação do vereador;
- biografia institucional;
- acesso direto ao Facebook e Instagram;
- layout adaptado para celulares e computadores;
- crédito da DSO Tech & Solutions no rodapé.

## Tecnologias

- React;
- TypeScript;
- Vite e Vinext;
- CSS responsivo.

## Executar no computador

É necessário ter o Node.js 22.13 ou mais recente.

```bash
npm install
npm run dev
```

Depois, abra o endereço informado no terminal.

## Gerar a versão de produção

```bash
npm run build
```

## Estrutura principal

- `app/page.tsx`: conteúdo da página;
- `app/globals.css`: cores, layout e responsividade;
- `public/images/`: foto oficial;
- `app/layout.tsx`: título e informações da página.
